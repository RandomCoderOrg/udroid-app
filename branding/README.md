# uDroid app icon

The Android app uses the existing uDroid logo without generative or creative
modification.

- Source:
  [`udroid-logo.png`](https://github.com/RandomCoderOrg/ubuntu-on-android/blob/modified/assets/udroid-logo.png)
- Source dimensions: `4831 × 4831` RGBA PNG
- Source SHA-256:
  `8621055fc00c37aafe7e2526bd853314e67862fc15530942efbbfe1aad1f8212`

The packaged files are deterministic proportional resizes of that source:

| Resource | Size |
| --- | ---: |
| Play Store, in-app, and adaptive artwork | 512 × 512 |
| `mipmap-mdpi` | 48 × 48 |
| `mipmap-hdpi` | 72 × 72 |
| `mipmap-xhdpi` | 96 × 96 |
| `mipmap-xxhdpi` | 144 × 144 |
| `mipmap-xxxhdpi` | 192 × 192 |

Round launcher icons use the same circular source artwork. Android 8 and newer
use the adaptive icon wrapper; older launchers use the density-specific PNGs.
